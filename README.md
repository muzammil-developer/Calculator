# Responsive Calculator 🧮

A modern, responsive, and user-friendly calculator built using **HTML5, CSS3, Bootstrap, and JavaScript**. It features a clean interface and works smoothly across desktop, tablet, and mobile devices.

## 🚀 Live Demo

[View Live Calculator](YOUR_LIVE_DEMO_LINK)

## ✨ Features

- Responsive design for all screen sizes.
- Clean and modern user interface.
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
- Interactive calculator buttons.
- Real-time calculation display.
- Clear (AC) functionality.
- Delete (DEL) functionality.
- Smooth and user-friendly experience.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Custom styling and design.
- **Bootstrap** – Responsive layout and components.
- **JavaScript** – Calculator functionality and logic.

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/muzammil-developer/Calculator/tree/main
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
